# Concepts

* [Feature Flag Conventions](SKILL.md) - The shared Cargo feature-flag naming and semantics contract across xberg-io Rust libraries — the same flag names mean the same thing everywhere (otel, mcp/mcp-http, mimalloc/jemalloc, acceleration). Load when adding, renaming, or reviewing a crate's \[features\], or reconciling a library's flags with the rest of the stack.
