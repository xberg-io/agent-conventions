# Org architecture decision records

The org-wide decision log is [`adrs/`](../adrs/), in MADR 4 as adrlint generates it; ADR 0000 records the
convention. Repository logs cite these records as `org ADR-NNNN` instead of restating them. This index lives outside
`adrs/` because adrlint lints every Markdown file in the log; add a row in the same change as a new record.
